# Introdução à Computação

Disciplina de Introdução à Computação - Fundamentos de computação com foco em desenvolvimento web.

## 📚 Conteúdo

Materiais e exercícios sobre:
- Conceitos fundamentais de computação
- Introdução à programação
- Desenvolvimento Web
- HTML, CSS e JavaScript
- Estrutura cliente-servidor
- Conceitos básicos de backend

## 🎯 Objetivos

- Compreender conceitos fundamentais da computação
- Aprender os fundamentos de desenvolvimento web
- Desenvolver habilidades de programação para web
- Entender a arquitetura de aplicações web
- Criar suas primeiras aplicações web

## 🌐 Tecnologias Abordadas

### Frontend
- **HTML**: Estrutura de documentos web
- **CSS**: Estilização e layout
- **JavaScript**: Interatividade e lógica do lado do cliente

### Backend
- Introdução a processamento server-side
- APIs e comunicação cliente-servidor

## 📖 Tópicos Principais

- Introdução à Internet e Web
- Estrutura básica de uma página HTML
- Estilização com CSS
- Programação com JavaScript
- DOM (Document Object Model)
- Eventos e interatividade
- Requisições HTTP
- Introdução a frameworks (se aplicável)

## 🛠️ Ferramentas

- Editor de código (VSCode recomendado)
- Navegador web moderno
- Ferramentas de desenvolvedor do navegador

## 🚀 Como Começar

1. Abra os arquivos HTML em seu navegador
2. Use as ferramentas de desenvolvedor (F12) para inspecionar código
3. Modifique e experimente o código
4. Consulte os materiais para entender os conceitos

## 📝 Notas

- Este é um curso introdutório para iniciantes
- Exemplos práticos facilitam o aprendizado
- Recomenda-se praticar codificando ao acompanhar os materiais
- A prática é essencial para dominar desenvolvimento web
