# Arquitetura e Organização

Disciplina sobre Arquitetura de Computadores e Organização de Sistemas.

## 📚 Conteúdo

Materiais e exercícios relacionados a:
- Arquitetura de computadores
- Organização de processadores
- Memória e cache
- Sistemas de I/O
- Microarquitetura
- Conjunto de instruções

## 🎯 Objetivos

- Compreender a arquitetura fundamental de computadores
- Entender como os componentes de hardware interagem
- Aprender sobre otimizações de desempenho
- Conhecer diferentes paradigmas de arquitetura

## 📖 Tópicos Principais

- Componentes básicos do computador
- Processadores e unidades de controle
- Hierarquia de memória
- Operações de entrada e saída
- Pipelines de instruções
- Paralelismo

## 🛠️ Tecnologias e Ferramentas

- Simuladores de arquitetura (se aplicável)
- Linguagens de descrição de hardware (VHDL, Verilog - se aplicável)

## 📝 Notas

- Este é um curso teórico-prático focado em conceitos fundamentais
- Exemplos e diagramas estão nos materiais fornecidos
