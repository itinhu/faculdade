# Algoritmo

Disciplina de Algoritmos - Fundamentos e técnicas de desenvolvimento algorítmico.

## 📁 Conteúdo

### Exercícios
Scripts Python com exercícios práticos de algoritmos, organizados numericamente:
- `code1.py` a `code13.py` - Diversos exercícios de algoritmos

### Slides
Materiais teóricos, apresentações e referências da disciplina.

## 🎯 Objetivos

- Compreender conceitos fundamentais de algoritmos
- Praticar resolução de problemas computacionais
- Desenvolver habilidades de programação em Python
- Aprender estruturas de dados e algoritmos clássicos

## 🛠️ Tecnologias

- **Linguagem**: Python 3

## 🚀 Como Executar

1. Navegue até a pasta de exercícios:
```bash
cd Exercicios
```

2. Execute um exercício:
```bash
python code1.py
```

## 📝 Notas

- Cada arquivo contém um ou mais exercícios com suas soluções
- Os exercícios estão ordenados por nível de dificuldade
- Use o `.gitignore` para evitar commits de arquivos compilados
