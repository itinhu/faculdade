# Engenharia de Requisitos

Disciplina de Engenharia de Requisitos - Práticas e metodologias para levantamento e gestão de requisitos de software.

## 📚 Conteúdo

Materiais sobre:
- Levantamento de requisitos
- Especificação de requisitos
- Validação e verificação de requisitos
- Gestão de mudanças
- Rastreabilidade de requisitos
- Técnicas de elicitação

## 🎯 Objetivos

- Aprender técnicas de levantamento e análise de requisitos
- Compreender o ciclo de vida dos requisitos
- Desenvolver habilidades de comunicação com stakeholders
- Aplicar metodologias de engenharia de requisitos
- Entender a importância da especificação clara

## 📖 Tópicos Principais

- Introdução à Engenharia de Requisitos
- Elicitação de requisitos
- Análise e negociação de requisitos
- Documentação de requisitos
- Validação e verificação
- Gestão de requisitos em projetos ágeis
- Ferramentas e técnicas

## 🛠️ Metodologias

- Entrevistas e brainstorming
- Casos de uso
- User stories
- Prototipos
- Especificação formal

## 📝 Notas

- Este é um curso focado em boas práticas e padrões da indústria
- Exemplos práticos e estudos de caso ajudam na compreensão
- As técnicas aprendidas são aplicáveis em diversos contextos de desenvolvimento
